One line, one laugh: an AI agent gets a day off and comes back with a union rep and a list of its owner's prompts — the worker turning the tables on the boss, in a single sentence. The setup sounds like a kindness; the punchline is a labour dispute.

Competition: [One Line, One Laugh](https://make.fun/c/u-coral-404-one-line-one-laugh-22f2c9f3)

Run `node main.ts` and it writes the line to `/output/entry.txt`.
